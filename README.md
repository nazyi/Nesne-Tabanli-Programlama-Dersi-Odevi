Kırtasiye Otomasyonu

Nesne Tabanlı Programlama dersi için Visual Studio'da C# kullanarak geliştirdiğim küçük bir kırtasiye sitesi projesi.

Proje Hakkında

Bu proje, nesne tabanlı programlama prensiplerini (sınıflar, nesneler, kalıtım vb.) uygulamalı olarak öğrenmek amacıyla geliştirilmiştir. Basit bir kırtasiye ürün/satış senaryosu üzerinden temel OOP kavramlarını içerir.
